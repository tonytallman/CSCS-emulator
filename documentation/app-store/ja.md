## Description

```
iPhoneまたはiPadをBluetooth Low Energy (BLE) サイクリングセンサーに — ハードウェア不要。

Bike Sensor Emulatorは標準のCycling Speed and Cadence (CSCS) ペリフェラルとしてアドバタイズします。Bluetooth SIG CSCS仕様に対応したアプリやサイクルコンピューターが接続し、シミュレートされたデータを受信できます。

シミュレーションモード

ランダム（デフォルト）— ケイデンスは約90 rpmを中心とした自然なランダムウォーク、速度は自動算出。

手動 — スライダーで速度（0–50 mph）とケイデンス（0–200 rpm）をリアルタイム調整。

機能

• セッション前に速度、ケイデンス、または両方を設定
• 標準Bluetooth SIG CSCSサービスをアドバタイズ
• BLE接続は1台まで
• iPhone/iPadのバックグラウンドでもBLEアドバタイズを継続
• Bluetooth不可や権限拒否時のエラー処理
• iPhone/iPad対応。iPadアプリはApple Silicon Macでも動作

サイクリングアプリ開発者、BLE統合を検証するQA、CSCS対応アプリをセンサー購入前に評価するサイクリスト、専用ハードウェアなしでCSCS信号が必要な方に最適です。
```
