## Description

```
iPhone 또는 iPad를 Bluetooth Low Energy(BLE) 사이클링 센서로 — 하드웨어 없이.

Bike Sensor Emulator는 표준 Cycling Speed and Cadence (CSCS) 주변 기기로 어드버타이징합니다. Bluetooth SIG CSCS 사양을 지원하는 앱이나 자전거 컴퓨터가 연결하여 시뮬레이션 데이터를 받을 수 있습니다.

시뮬레이션 모드

랜덤(기본) — 케이던스가 약 90 rpm 중심의 자연스러운 랜덤 워크, 속도는 자동 계산.

수동 — 슬라이더로 속도(0–50 mph)와 케이던스(0–200 rpm)를 실시간 조절.

기능

• 세션 전 속도, 케이던스 또는 둘 다 구성
• 표준 Bluetooth SIG CSCS 서비스를 어드버타이징
• BLE 연결 1대까지
• iPhone/iPad의 백그라운드에서도 BLE 어드버타이징 지속
• Bluetooth 사용 불가 및 권한 거부 시 오류 처리
• iPhone/iPad 지원. iPad 앱은 Apple Silicon Mac에서도 실행

사이클링 앱 개발자, BLE 센서 통합을 검증하는 QA 팀, 센서 구매 전 CSCS 호환 앱을 평가하는 사이클리스트, 전용 하드웨어 없이 CSCS 신호가 필요한 사용자에게 이상적입니다.
```
